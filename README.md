My data engineering learning journey, documented.

- A star-schema design for sample retail data
- Everything tested, documented and committed here

## Current phase

## How this repo works
- Every study session gets an entry in [`LOG.md`](LOG.md): the question, my first approach, my final solution, and a comment.
- Solutions are saved in the matching folder and committed the same day.

## Structure
| Path | What's inside |
|---|---|

| `sql/` | SQL practice and solutions |
